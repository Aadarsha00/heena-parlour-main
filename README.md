# Beautiful Brows & Henna website

React, TypeScript, and Vite frontend for salon services, live appointment
availability, bookings, customer appointments, blog/gallery content, and
contact enquiries. Booking is online; payment is handled in person at the
parlour.

## Local setup

```powershell
npm install
npm run dev
```

Create `.env` from `.env.example` and set `VITE_API_BASE_URL`, for example
`http://localhost:8000/api`.

## Validation

```powershell
npm run lint
npm run build
npm audit
```
